<h2>v1.1.5 - Ender Dragon respawn fixes</h2>

<h3>Fix</h3>
<ul>
<li><strong>Dragon respawn placed fabricated bedrock</strong>: YUNG's Better End Island generates its exit-portal bedrock towers at a non-uniform distance (7-8 blocks, not exactly 7) in each cardinal direction. The previous fixed-distance search missed real towers and created fake bedrock instead of using the one already generated.</li>
<li><strong>Duplicate crystals</strong>: repeated server restarts before the respawn sequence completed could place overlapping end crystals. The handler now checks for an existing crystal nearby before placing a new one.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>EnderDragonRespawnHandler.findExistingBedrockTower()</code> — scans a distance range (6-9 blocks) with lateral tolerance instead of assuming a fixed offset, and never creates new bedrock.</li>
<li><code>EnderDragonRespawnHandler.hasNearbyCrystal()</code> — skips placement if an <code>EndCrystal</code> already exists near the target position.</li>
<li>Removed <code>placeVanillaCrystals()</code> (dist=2), which fabricated fake bedrock unrelated to YUNG BEI's real structure.</li>
</ul>
