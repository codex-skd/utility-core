<h2>v2.2.0 - Invalid JAR Fix + Config Files Moved</h2>

<h3>Fix</h3>
<ul>
<li><strong>Critical</strong>: 2.1.2's sibling release (QoL) shipped an invalid <code>neoforge.mods.toml</code> due to a build-script bug in the shared version-templating step, which could affect any Utility Core mod using a <code>credits</code>/description field with an escaped line break. Fixed at the build level for all 3 mods.</li>
</ul>

<h3>Change</h3>
<ul>
<li>The mod's config file now lives at <code>config/utility_core/utility_core_admin-common.toml</code> instead of directly in <code>config/</code>, grouping it with the other Utility Core mods (Fixes, QoL).</li>
</ul>

<blockquote><strong>Breaking</strong>: if you're updating from an earlier version, your existing config at <code>config/utility_core_admin-common.toml</code> is <strong>not</strong> migrated automatically. It stays on disk (orphaned) and a new config with default values is generated at <code>config/utility_core/utility_core_admin-common.toml</code>. Copy your settings over manually if you want to keep them.</blockquote>
