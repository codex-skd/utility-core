<h2>v1.1.7 - Remove Ender Dragon respawn feature</h2>

<h3>Removed</h3>
<ul>
<li><strong>Automatic Ender Dragon respawn</strong>: removed entirely (<code>EnderDragonRespawnHandler</code> and the <code>enableEndDragonRespawn</code> config option). With YUNG's Better End Island installed, the crystals placed at the vanilla-required trigger distance end up floating without real support, giving a broken-looking result. Matching YUNG's custom exit portal structure precisely was not worth the added complexity, so the feature is removed instead of patched further.</li>
</ul>
