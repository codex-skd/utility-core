<h2>v1.11.2 - Recipe Selector Display Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Recipe selector disappearing with multiple recipes</strong>: When the crafting table recipe selector displayed multiple recipes, the selector grid was rendered at a fixed position that could exceed the visible screen bounds, causing it to disappear or render outside the GUI. The selector now dynamically calculates its layout and repositions itself to stay within the visible screen area.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>PolymorphClientHandler</code> &mdash; refactored <code>renderRecipeSelector()</code> to calculate columns based on available screen space instead of a fixed 4-column grid. Added height-aware layout that increases columns if rows would exceed the vertical bounds. Grid position is clamped to keep the entire selector within screen limits.</li>
<li>Added <code>selectorColumns</code> field to dynamically track the column count per render and ensure click hit-testing matches the rendered layout.</li>
</ul>
