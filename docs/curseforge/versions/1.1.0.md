<h2>v1.1.0 - Biome/Dimension Titles</h2>

<h3>New Feature</h3>
<ul>
<li><strong>Biome/Dimension Titles</strong>: shows a title on screen when entering a new biome or dimension. Toggle via <code>enableBiomeDimensionTitles</code> (default true). Logic ported from <a href="https://www.curseforge.com/minecraft/mc-mods/travelers-titles">Traveler's Titles</a> by YUNGNICKYOUNG (LGPLv3), rebuilt on vanilla's own title HUD instead of a custom renderer.</li>
</ul>
