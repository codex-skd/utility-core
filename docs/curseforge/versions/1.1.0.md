<h2>v1.1.0 - Multi-Dimension ChunkGen</h2>

<h3>Feature</h3>
<ul>
<li><strong>Multi-dimension chunk generation</strong>: Now supports pre-generating chunks in the Overworld, Nether, and The End simultaneously. Each dimension has its own spiral state and progress tracking.</li>
<li><strong>Configurable dimensions</strong>: Toggle which dimensions to generate via <code>chunkGen.dimensionOverworld</code>, <code>chunkGen.dimensionNether</code>, <code>chunkGen.dimensionEnd</code>.</li>
<li><strong>Keep server alive</strong>: New <code>chunkGen.keepAlive</code> option (default: true) prevents the server from pausing during generation.</li>
<li><strong>Higher throughput</strong>: <code>chunkGen.chunksPerTick</code> max increased from 64 to 300.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>ChunkGenManager</code> &mdash; Complete rewrite: now manages a <code>Map&lt;String, DimState&gt;</code> with separate spiral states per dimension. Cycles through dimensions each tick.</li>
<li><code>Config.java</code> &mdash; Added 3 dimension toggles + keepAlive option.</li>
</ul>
