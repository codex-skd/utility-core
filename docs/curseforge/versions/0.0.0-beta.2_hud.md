<h2>v0.0.0-beta.2 - Fixed Event Bus Registration</h2>

<h3>Fix</h3>
<ul>
<li><strong>RegisterClientCommandsEvent registration</strong>: Fixed crash on startup caused by registering <code>RegisterClientCommandsEvent</code> listener on the mod event bus instead of <code>NeoForge.EVENT_BUS</code>. The event is not an <code>IModBusEvent</code> and must be registered on the NeoForge event bus.</li>
</ul>

<h3>Features (from beta.1)</h3>
<ul>
<li><strong>Armor Durability HUD</strong>: Displays equipped armor pieces (helmet, chestplate, leggings, boots) with durability overlay, matching inventory icon style. Icons always stay contiguous — no gaps when pieces are removed.</li>
<li><strong>In-Game Guide Book (Vellumli)</strong>: Explains all HUD features. Informs users to use <code>/hudmenu</code> command (requires OP level 2).</li>
<li><strong>Interactive Position Editor</strong>: Buttons for <code>+</code>/<code>-</code> scale, <code>Done</code> to save, <code>Cancel</code> to discard changes.</li>
<li><strong>Show / Never Show Toggle</strong>: Cycle through Show → Never Show → Show states from the menu.</li>
</ul>

<h3>Commands</h3>
<ul>
<li><code>/hudmenu</code> — Opens HUD configuration menu (requires operator permission level 2)</li>
</ul>

<h3>Technical</h3>
<ul>
<li>Config saved to <code>config/utility_core_hud/hud_config.json</code> (position, orientation, scale, visibility)</li>
<li>Client-only mod for NeoForge 26.2.0.57 / Minecraft 26.2</li>
<li>Required dependency: <a href="https://www.curseforge.com/minecraft/mc-mods/vellumli">Vellumli</a></li>
</ul>
