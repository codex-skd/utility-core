<h2>v1.1.1 - Bugfix release</h2>

<h3>Fix</h3>
<ul>
<li><strong>ChunkGen resume</strong>: generation did not restart after loading saved state from JSON because <code>start()</code> never set <code>running = true</code> when dimensions already existed in the map. Now resumes correctly from where it left off.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>ChunkGenManager.start()</code> — early return with <code>running = true</code> if state was loaded from disk, instead of trying to re-initialize dimensions that already exist.</li>
<li>Workspace reorganized to <code>utility_core/26.1.2/</code> structure.</li>
<li>WORKFLOW updated to v1.4.0.</li>
</ul>
