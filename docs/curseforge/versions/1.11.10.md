<h2>v1.11.10 - Recipe Selector Disabled</h2>

<h3>Status</h3>
<ul>
<li><strong>Recipe selector feature disabled by default</strong>: After extensive debugging, we discovered that the server-side mixin for detecting multiple recipes has a fundamental issue with parameter alignment in Minecraft 26.2. The `CraftingContainer` being passed to the recipe detection method contains empty slots (air) rather than the actual crafting ingredients. This causes the server to never detect valid recipes and the selector fails completely.</li>
<li>The feature has been disabled by default while a proper fix is investigated.</li>
</ul>

<h3>What's Wrong</h3>
<ul>
<li>The mixin injection point parameters appear misaligned with the actual method signature in MC 26.2</li>
<li>Server logs show: "Recipe calculation: 0 recipes found for input [AIR, AIR, AIR, AIR]" even when ingredients are placed</li>
<li>This is a deep structural issue that needs investigation of the `CraftingMenu.slotChangedCraftingGrid()` method signature</li>
</ul>
