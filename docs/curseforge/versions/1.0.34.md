<h2>v1.0.34 - Ender Dragon Respawn: YUNG Better End Island Compatibility</h2>

<h3>Fix</h3>
<ul>
<li><strong>Dragon respawn with YUNG Better End Island</strong>: Crystals were placed at distance 3, but YUNG checks for crystals at distance 7 (BEI radius) or distance 2 (vanilla radius). Now places crystals at both distances.</li>
<li><strong>Removed fragile reflection to YUNG internal API</strong>: <code>advanceRespawnStage(START)</code> called via reflection on <code>IBetterDragonFight</code> threw <code>IllegalStateException</code>. Now uses <code>fight.tryRespawn()</code> which YUNG overrides natively via <code>spawnDragon()</code>.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>EnderDragonRespawnHandler</code> &mdash; Rewritten: detects YUNG via <code>Class.forName()</code>, places crystals at dist=7 (BEI) or dist=2 (vanilla), delegates to <code>fight.tryRespawn()</code></li>
<li>YUNG flow: <code>tryRespawn()</code> &rarr; <code>betterendisland_tryRespawn()</code> &rarr; <code>spawnDragon()</code> &rarr; <code>checkForBEIRespawnCrystals(dist=7)</code></li>
</ul>
