<h2>v2.4.0 - Underground Biome Title Fix</h2>

<h3>Add</h3>
<ul>
<li><strong>Underground biome title control</strong>: new <code>enableUndergroundBiomeTitles</code> config option (default <code>true</code>). Underground, Minecraft's biome graph usually reports the same biome as the surface above the player (cave-specific biomes like Lush Caves, Dripstone Caves or Deep Dark are the exception), so the biome title could show a misleading surface biome name while caving. Disable this option to suppress the biome title whenever the player can't see the sky.</li>
</ul>
