<h2>v2.5.0 - Nether Return Portal Fix</h2>

<h3>Add</h3>
<ul>
<li><strong>Nether return portal fix</strong>: remembers which portal you departed from every time you cross between the Overworld and the Nether, paired with the portal you arrived at. On the return trip, if that remembered portal still exists, you're redirected to it instead of vanilla's error-prone "closest portal" search — which could otherwise send you through the wrong portal when several exist nearby. Falls back to vanilla behavior if the remembered portal no longer exists. Toggle: <code>enableNetherReturnPortalFix</code> (enabled by default).</li>
<li><strong>JAR name with loader version</strong>: artifact now builds as <code>utility_core_fixes-26.2-neoforge-26.2.0.57-2.5.0.jar</code>.</li>
</ul>
