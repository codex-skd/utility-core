<h2>v1.2.0 - Spawn Schematic (Opt-in)</h2>

<h3>New Feature</h3>
<ul>
<li><strong>Spawn Schematic</strong>: pastes a WorldEdit/FAWE Sponge Schematic (<code>.schem</code>) at world creation, permanently protects the pasted area, and sets the world spawn point inside the structure. Toggle via <code>enableSpawnSchematic</code> (default false). Place the file at <code>schematics/schematic_spawn.schem</code> (sibling of the <code>mods/</code> folder).</li>
</ul>

<blockquote><strong>IMPORTANT:</strong> only works on a brand-new world save (no existing region files). To apply to an already-existing world, you must delete the world save folder first, then start the server with this enabled. This is intentional.</blockquote>
