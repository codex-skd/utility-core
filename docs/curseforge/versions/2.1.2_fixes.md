<h2>v2.1.2 - Dedicated Server Crash Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Critical</strong>: <code>registerExtensionPoint(IConfigScreenFactory.class, ConfigurationScreen::new)</code> ran unconditionally in the mod constructor. <code>ConfigurationScreen</code> extends the client-only <code>Screen</code> class, so classloading it threw <code>NoClassDefFoundError: net/minecraft/client/gui/screens/Screen</code> on any dedicated server, crashing the whole mod load. The registration is now gated behind <code>FMLEnvironment.dist.isClient()</code>.</li>
<li><strong>Metadata</strong>: the mod's declared <code>version</code> in <code>neoforge.mods.toml</code> was hardcoded to the literal <code>2.0.0</code> and never reflected the real build version. It now resolves dynamically from the Gradle project version.</li>
</ul>

<blockquote>Critical update if you run Fixes on a dedicated server — 2.1.0 and 2.1.1 do not load there at all.</blockquote>
