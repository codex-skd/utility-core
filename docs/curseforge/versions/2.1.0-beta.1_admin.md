<h2>v2.1.0-beta.1 - Standalone Mod Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Critical</strong>: Admin had no <code>@Mod</code> entrypoint class and never registered its <code>ModConfigSpec</code>, so it did not generate its own config file and did not function as a real standalone mod. Added <code>UtilityCoreAdmin</code> with proper config registration.</li>
<li><strong>Crash on load</strong>: <code>ServerStartingEvent</code>, <code>ServerStartedEvent</code> and <code>ServerTickEvent</code> were registered on the mod event bus instead of <code>NeoForge.EVENT_BUS</code>, throwing an <code>IllegalArgumentException</code> on startup.</li>
<li><strong>Crash on world start</strong>: <code>SpawnSchematicManager</code> was never instantiated, causing a <code>NullPointerException</code> when the integrated server started.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Removed the obsolete duplicate <code>Config.java</code> from the parent project and an orphaned stray <code>neoforge.mods.toml</code>.</li>
<li>Fixed subproject version resolution in the root <code>build.gradle</code> (was hardcoded, ignored <code>mod_version</code> bumps).</li>
</ul>

<blockquote>Recommended update if you are running Admin on a server — the previous 2.0.0-beta.1 build did not load correctly.</blockquote>
