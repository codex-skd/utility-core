<h2>v1.7.0 - Data Pack Folder Loader</h2>

<h3>New Feature</h3>
<ul>
<li><strong>Data Pack Folder</strong>: loads every datapack (<code>.zip</code> or folder with a <code>pack.mcmeta</code>) placed in <code>&lt;game-dir&gt;/datapacks</code> into every world automatically, mirroring the Global Packs mod. Packs are registered with <code>required=true</code>, so they are <strong>always enabled</strong> — no per-world toggle needed. Works on dedicated servers and in single-player (integrated server); a client connecting to a dedicated server receives the datapacks from the server as usual.</li>
<li>Invalid datapacks (missing/broken <code>pack.mcmeta</code>) are skipped.</li>
</ul>

<h3>Config</h3>
<ul>
<li><code>dataPackFolder.enabled</code> (default false) — master toggle.</li>
<li><code>dataPackFolder.path</code> (default <code>datapacks</code>) — folder scanned, relative to the game directory.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>DataPackFolderLoader</code> — new; registers a <code>RepositorySource</code> via <code>AddPackFindersEvent</code> (<code>PackType.SERVER_DATA</code>) using <code>Pack.readMetaAndCreate</code> with a required <code>PackSelectionConfig</code>.</li>
</ul>
