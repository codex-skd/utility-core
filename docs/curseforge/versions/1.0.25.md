<h2>v1.0.25 - Ender Dragon Respawn: YUNG Better End Island Compatibility Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Ender Dragon respawn with YUNG Better End Island</strong>: <code>tryRespawn()</code> is a no-op when YUNG is present (mixin overrides the method). The handler now detects YUNG via reflection and calls <code>advanceRespawnStage(START)</code> on YUNG's native 5-stage respawn machine.</li>
<li><strong>Crystal stacking on server restart</strong>: Manual crystal placement around the exit portal has been removed. YUNG's own respawn process handles pillar building and crystal placement automatically.</li>
<li><strong>Double tryRespawn() call</strong>: The redundant second call that corrupted the respawn state machine has been removed.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>EnderDragonRespawnHandler</code> now uses YUNG's <code>IBetterDragonFight.advanceRespawnStage(START)</code> via reflection when YUNG is detected</li>
<li>Falls back to vanilla <code>tryRespawn()</code> when YUNG is not present</li>
<li>All manual crystal placement code removed (no more stacking on restarts)</li>
</ul>
