<h2>v2.3.2 - Force pause safety option for chunk generation</h2>

<h3>Add</h3>
<ul>
<li><strong>Force pause chunk generation</strong>: new config option <code>chunkGen.forcePause</code> (default: <code>false</code>) acts as an emergency safety override. When set to <code>true</code>, chunk generation will never run even if <code>chunkGen.enabled = true</code>. Useful as a safety measure to prevent any accidental generation.</li>
</ul>
