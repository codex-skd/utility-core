<h2>v1.11.0 - External Spawn Schematic, Protection Toggle &amp; Protected-Area Message</h2>

<h3>Breaking Changes</h3>
<ul>
<li><strong>Spawn schematic no longer bundled in the mod</strong>: the JAR no longer ships a default <code>.schem</code> and the mod no longer extracts one automatically. You must place your own schematic at <code>&lt;game-dir&gt;/utility_core/spawn_schem/schematic_spawn.schem</code> <em>before</em> creating/regenerating a world. If the file is missing, the feature is skipped with a log error. (This also removes the large binary payload from the mod jar.)</li>
</ul>

<h3>New Features</h3>
<ul>
<li><strong>Spawn protection toggle command</strong>: <code>/utilitycore spawnprotection on|off|status</code> toggles the build protection of the spawn schematic area at runtime (block breaking/placing and explosions), so operators can temporarily build inside the protected zone and re-enable it. The state persists to the config.</li>
<li><strong>Protected-area message</strong>: when a player tries to break or place a block inside the protected zone, they get a message telling them the area is protected and how many blocks they must move out of the zone.</li>
</ul>

<h3>Config</h3>
<ul>
<li><code>spawnSchematic.protectionEnabled</code> &mdash; default <code>true</code>. Build protection of the spawn area; toggled at runtime with <code>/utilitycore spawnprotection</code>.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>SpawnSchematicManager</code> &mdash; removed the bundled-schematic resource and <code>extractDefaultSchematic()</code>; added <code>distanceToExit()</code> and public bounds getters; protection now also checks <code>spawnSchematic.protectionEnabled</code>.</li>
<li><code>SpawnProtectionHandler</code> &mdash; notifies the offending player with the distance to exit the zone.</li>
<li><code>UtilityCore</code> &mdash; new <code>spawnprotection</code> subcommand (persists via <code>ConfigValue.set()/save()</code>).</li>
<li><code>Config</code> &mdash; new <code>SPAWN_SCHEMATIC_PROTECTION_ENABLED</code> option; spawn schematic comments updated (no bundled default).</li>
</ul>

<h3>Notes</h3>
<blockquote>Existing worlds that already placed a schematic keep their protection bounds (stored in the world marker). For a brand-new world, drop your <code>.schem</code> into <code>utility_core/spawn_schem/schematic_spawn.schem</code> and create the world. The example lobby schematic is available in the release download folder.</blockquote>
