<h2>v1.0.35 - ChunkGen: Server Shutdown Persistence</h2>

<h3>Feature</h3>
<ul>
<li><strong>ChunkGen state saved on server stop</strong>: Progress is now saved when the server shuts down via <code>ServerStoppingEvent</code>, preventing progress loss on clean shutdowns.</li>
<li><strong>Startup logging</strong>: ChunkGen now logs previous progress when the server starts: <code>[ChunkGen] Ready. Previous progress: X chunks generated up to radius Y</code>.</li>
</ul>

<h3>Fix</h3>
<ul>
<li><strong>Version restored</strong>: Fixed production branch version that was overwritten by CI-main sanitization process.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>ChunkGenManager.onServerStopping()</code> &mdash; Saves state and logs final position on server shutdown</li>
<li><code>UtilityCore.onServerStarted()</code> &mdash; Logs ChunkGen previous progress on server start</li>
<li><code>UtilityCore.onServerStopping()</code> &mdash; Calls <code>ChunkGenManager.onServerStopping()</code></li>
</ul>
