<h2>v1.3.1 - Critical Crash Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Client crash on startup (v1.3.0)</strong>: <code>MixinTransformerError</code> / <code>InjectionError</code> in <code>MixinHud</code>. The <code>@ModifyArg</code> injection target had the wrong return-type descriptor (<code>(FF)V</code> instead of <code>(FF)Lorg/joml/Matrix3x2f;</code>), so the injection point never matched the real method and Mixin treated it as fatal. Verified against the actual compiled <code>Hud.class</code> bytecode with <code>javap</code>.</li>
</ul>
