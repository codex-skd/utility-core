<h2>v1.8.0 - ChunkGen Duty Cycle &amp; Guaranteed Pause on Player Join (ported to 26.1.2)</h2>

<h3>New Features</h3>
<ul>
<li><strong>ChunkGen duty cycle</strong>: chunk pregeneration now works in wall-clock blocks &mdash; <code>chunkGen.loadSeconds</code> (default 600 = 10 min) of generation followed by <code>chunkGen.restSeconds</code> (default 300 = 5 min) of rest with no generation, giving the server periodic breaks. The cycle is measured in real time (not ticks), because generating chunks with heavy structure mods can run the server at low TPS.</li>
<li><strong>Guaranteed pause when a player joins</strong>: generation now stops as soon as a connection reaches the login/configuration handshake (via <code>ServerLoginPacketListenerImpl</code>/<code>ServerConfigurationPacketListenerImpl</code>), not only after the player fully joins. It also aborts mid-batch inside a <code>chunksPerTick</code> block, and <code>onPlayerJoin</code> forces the pause directly. This brings the 26.1.2 branch to feature parity with 26.2.</li>
</ul>

<h3>Config</h3>
<ul>
<li><code>chunkGen.loadSeconds</code> (default 600, range 60-86400) &mdash; seconds of generation before a rest period.</li>
<li><code>chunkGen.restSeconds</code> (default 300, range 0-86400) &mdash; seconds of rest with no generation.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>ChunkGenManager</code> &mdash; added duty-cycle state machine (<code>restPhase</code>/<code>phaseStartMillis</code>), connection-based player detection (<code>hasJoiningConnection</code>), and mid-batch abort when a player starts joining.</li>
<li><code>Config</code> &mdash; new <code>CHUNK_GEN_LOAD_SECONDS</code> / <code>CHUNK_GEN_REST_SECONDS</code> options.</li>
</ul>

<h3>Notes</h3>
<blockquote>Server operators: the new config keys are added automatically on first start (<code>loadSeconds</code>=600, <code>restSeconds</code>=300). If you want the server to rest more often, lower <code>chunkGen.loadSeconds</code> or raise <code>chunkGen.restSeconds</code>.</blockquote>
