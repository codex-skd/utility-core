<h2>v1.1.3 - Multi-dimension ChunkGen &amp; Dragon respawn fixes</h2>

<h3>Fix</h3>
<ul>
<li><strong>ChunkGen multi-dimension</strong>: when resuming from saved state (e.g. Overworld with 95k chunks), Nether and End dimensions configured in <code>chunkGen.dimensionNether</code> / <code>chunkGen.dimensionEnd</code> are now also added and generated.</li>
<li><strong>Dragon respawn fallback</strong>: <code>placeCrystalWithBedrock</code> now also places crystals at vanilla positions (dist=2, portal Y-2) so <code>fight.tryRespawn()</code> can detect them and start the respawn countdown.</li>
<li><strong>Dragon respawn logging</strong>: added warnings when bedrock placement or crystal spawning fails.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>ChunkGenManager.start()</code> — rewritten to always check config for new dimensions, whether resuming from saved state or starting fresh.</li>
<li><code>EnderDragonRespawnHandler.placeCrystalWithBedrock()</code> — now places both YUNG-position (dist=7) and vanilla-position (dist=2) crystals to guarantee detection.</li>
</ul>
