<h2>v1.0.38 - Ender Dragon Respawn: Y-Level Scan for Bedrock</h2>

<h3>Fix</h3>
<ul>
<li><strong>Dragon respawn with YUNG Better End Island</strong>: The exit portal is at Y=63 (not Y=60). The bedrock towers can be at different Y levels depending on the island generation. Now scans Y levels from <code>portalY+10</code> down to <code>portalY-10</code> to find valid bedrock with air above for each crystal position.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>EnderDragonRespawnHandler.placeCrystalsAt()</code> &mdash; Scans Y axis for bedrock blocks in a 21-block range around the portal center, instead of checking only at the portal Y level.</li>
</ul>
