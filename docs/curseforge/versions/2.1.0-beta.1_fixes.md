<h2>v2.1.0-beta.1 - Standalone Mod Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Critical</strong>: Fixes had no <code>@Mod</code> entrypoint class and never registered its <code>ModConfigSpec</code>, so it did not generate its own config file and did not function as a real standalone mod. Added <code>UtilityCoreFixes</code> with proper config registration.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Removed the obsolete duplicate <code>Config.java</code> from the parent project and an orphaned stray <code>neoforge.mods.toml</code>.</li>
<li>Fixed subproject version resolution in the root <code>build.gradle</code> (was hardcoded, ignored <code>mod_version</code> bumps).</li>
</ul>

<p>No behavioral changes to the Tombstone fixes, negative damage fix, or OutpostZero damage cap in this release — this is purely the mod-loading fix.</p>

<blockquote>Recommended update — the previous 2.0.0-beta.1 build did not register its config and may not have functioned correctly as a standalone mod.</blockquote>
