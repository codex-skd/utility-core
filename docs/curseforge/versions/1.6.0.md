<h2>v1.6.0 - Lobby Spawn Schematic &amp; Legacy .schematic Support</h2>

<h3>Improvement</h3>
<ul>
<li><strong>New bundled lobby schematic</strong>: the default spawn schematic is now a large lobby build that floats <strong>70 blocks above the terrain</strong>. <code>spawnSchematic.surfaceOffset</code> defaults to 70 (was 0). The 26.1.2 build now also extracts the bundled default automatically when the file is missing, same as 26.2.</li>
<li><strong>Legacy WorldEdit/MCEdit support</strong>: the reader now auto-detects and parses the legacy <code>.schematic</code> format (<code>Materials=Alpha</code>: <code>Blocks</code>/<code>Data</code>/<code>AddBlocks</code> byte arrays plus <code>TileEntities</code>), so old WorldEdit files work in addition to Sponge v2/v3. A new block-ID table (<code>LegacyBlockMap</code>) translates pre-1.13 numeric IDs + metadata into modern block states (colors, slabs, stairs, logs, rails, etc.).</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>SpongeSchematicReader#parseLegacy</code> — legacy format parsing (auto-detected when the root has a <code>Blocks</code> byte array).</li>
<li><code>LegacyBlockMap</code> — full 0-255 legacy ID → <code>BlockState</code> mapping with common metadata variants.</li>
<li><code>Config</code> — <code>spawnSchematic.surfaceOffset</code> default changed from 0 to 70.</li>
</ul>

<h3>Notes</h3>
<blockquote>Applies only on a brand-new world. For an existing world, delete the world save folder and regenerate it.</blockquote>
