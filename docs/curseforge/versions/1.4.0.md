<h2>v1.4.0 - Spawn Schematic: Bundled Default &amp; World-Origin Anchor</h2>

<h3>Improvement</h3>
<ul>
<li><strong>New schematic path</strong>: the external schematic file now lives at <code>&lt;game-dir&gt;/utility_core/spawn_schem/schematic_spawn.schem</code> instead of <code>&lt;game-dir&gt;/schematics/schematic_spawn.schem</code>, matching the same folder pattern used by ChunkGen.</li>
<li><strong>Bundled example schematic</strong>: the mod now ships a default example schematic and extracts it automatically to the path above on the first server start if the file is missing, so the feature works out of the box. To use a custom schematic, simply replace <code>schematic_spawn.schem</code> with your own file (same filename) before creating or regenerating the world.</li>
<li><strong>World-origin anchor</strong>: the schematic is now pasted centered on world coordinates <strong>X=0, Z=0</strong> instead of the vanilla spawn point, with the base height still computed from the real terrain heightmap at that location. Area protection, the per-world marker, and the safe-spawn scan are unchanged.</li>
</ul>
