<h2>v1.7.1 - Biome/Dimension Titles (ported to 26.1.2)</h2>

<h3>New Feature</h3>
<ul>
<li><strong>Biome/Dimension Titles</strong>: shows a vanilla title on screen when the player enters a new biome or dimension, rebuilding the Traveler's Titles logic on vanilla's own title HUD. This brings the 26.1.2 branch to feature parity with 26.2.</li>
<li><code>enableBiomeDimensionTitles</code> (default true) — master toggle, client-side.</li>
<li><code>titleVerticalOffset</code> (default 75) — shifts the vanilla title/subtitle vertically from the screen center (-200 to 200).</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>BiomeDimensionTitleHandler</code> — new client handler using <code>ClientTickEvent.Post</code>.</li>
<li><code>MixinHud</code> — new; injects into <code>Gui.extractTitle</code> to apply the vertical offset (uses <code>Gui</code>, the 26.1.2 HUD class).</li>
</ul>
