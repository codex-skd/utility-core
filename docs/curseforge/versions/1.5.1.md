<h2>v1.5.1 - Fix: Tombstone GUI Scale Mixin Broken on Client</h2>

<h3>Fix</h3>
<ul>
<li><strong>Client mixin crash / Tombstone GUI scale fix broken</strong>: <code>MixinTBScreen</code> injected into <code>Screen.init(Minecraft, int, int)</code>, a method that no longer exists in this Minecraft version — the real entry point is the <code>final</code> method <code>init(int, int)</code>. The injection failed at runtime, breaking the Tombstone GUI scale fix on the client. The injection now targets <code>init(II)V</code> (runs for every screen and on resize), so the fix applies again.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>MixinTBScreen#onScreenInit</code> — retargeted from <code>init(Lnet/minecraft/client/Minecraft;II)V</code> to <code>init(II)V</code>; <code>Minecraft</code> is now obtained via <code>Minecraft.getInstance()</code>.</li>
</ul>
