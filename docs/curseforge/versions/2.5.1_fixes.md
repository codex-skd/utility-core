<h2>v2.5.1 - Crash Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Crash when crossing Nether portals</strong>: <code>ModAttachments.ATTACHMENT_TYPES</code> (the <code>return_portal_data</code> attachment storing return portal mappings) was created but never registered on the mod event bus. The attachment type remained "unbound" and the <code>MixinNetherReturnPortalFix</code> threw <code>NullPointerException: Trying to access unbound value: ResourceKey[neoforge:attachment_types / utility_core_fixes:return_portal_data]</code> when attempting to access portal data. Now <code>ModAttachments.ATTACHMENT_TYPES.register(modEventBus)</code> is called in <code>UtilityCoreFixes</code> constructor.</li>
<li><strong>JAR name with loader version</strong>: artifact now builds as <code>utility_core_fixes-26.2-neoforge-26.2.0.57-2.5.1.jar</code>.</li>
</ul>
