<h2>Utility Core 1.0.22</h2>

<h3>Added</h3>
<ul>
<li><strong>OutpostZero compatibility</strong>: Prevents armor from being instantly destroyed by the infection damage (<code>outpostzero:infection</code>) dealt by <code>OpzInfectionManager.onFinalInfectionStageExpired()</code>.</li>
</ul>

<h3>Technical Details</h3>
<ul>
<li>Registered <code>LivingDamageEvent.Pre</code> handler that caps infection damage from <code>Float.MAX_VALUE</code> to <code>10000</code> — enough to kill, insufficient to melt armor durability before death events fire.</li>
<li>Uses standard vanilla/NeoForge APIs only; no compile-time dependency on OutpostZero required.</li>
<li>Only intercepts <code>outpostzero:infection</code> damage type — other mods using high damage values are unaffected.</li>
</ul>

Compatible with Minecraft 26.1.2 (NeoForge 26.1.2.78)
