<h2>Utility Core 1.0.23</h2>

<h3>Added</h3>
<ul>
<li><strong>Configuration toggles</strong> for all features: Tombstone GUI scale fix, Tombstone item init fix, Tombstone error handler, negative damage fix, OutpostZero damage cap, and Ender Dragon auto-respawn.</li>
<li><strong>Ender Dragon auto-respawn</strong>: When enabled, automatically triggers the full vanilla respawn sequence (obsidian towers, crystals, animation) on server start if the dragon was previously killed.</li>
</ul>

<h3>Changed</h3>
<ul>
<li><code>Config.java</code> now includes bilingual (EN/ES) descriptions for all settings in the generated config file.</li>
<li>All Tombstone and OutpostZero fixes now respect their respective config toggles — they only activate when the corresponding mod is present <strong>and</strong> the setting is enabled.</li>
</ul>

<h3>Notes</h3>
<blockquote>Features that depend on specific mods (Tombstone, OutpostZero) automatically detect whether the mod is present. The config toggle only takes effect when the mod is actually loaded; if the mod is absent, the feature is skipped regardless of the config value.</blockquote>

Compatible with Minecraft 26.1.2 (NeoForge 26.1.2.78)
