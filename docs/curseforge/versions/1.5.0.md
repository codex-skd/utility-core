<h2>v1.5.0 - Spawn Schematic: Configurable Height Placement</h2>

<h3>Fix</h3>
<ul>
<li><strong>Schematic buried at Y=-64</strong>: on a brand-new world the chunk under the spawn area was not generated yet when the height was computed, so the heightmap returned the world's minimum build height (-64) and the schematic was pasted at the bottom of the world. The mod now force-generates all chunks under the schematic footprint before calculating placement.</li>
</ul>

<h3>Improvement</h3>
<ul>
<li><strong>Configurable height placement</strong>: three new options control where the bottom of the schematic is placed:
  <ul>
  <li><code>spawnSchematic.heightMode</code> (default <code>SURFACE</code>): aligns the bottom of the schematic to the highest ground block under its footprint, so the structure sits on the terrain instead of being buried.</li>
  <li><code>spawnSchematic.surfaceOffset</code> (default 0): extra blocks above the ground in <code>SURFACE</code> mode — 0 = flush with the ground, positive = raised, negative = buried.</li>
  <li><code>spawnSchematic.fixedY</code> (default 64): absolute Y coordinate used when <code>heightMode=FIXED</code>.</li>
  </ul>
</li>
<li><strong>Footprint surface detection</strong>: in <code>SURFACE</code> mode the highest ground block across the whole footprint is used (not a single column), so the structure does not end up half-buried on irregular terrain.</li>
</ul>

<h3>Notes</h3>
<blockquote>Configuration only applies on a brand-new world. To apply it to an already-existing world, delete the world save folder and regenerate it.</blockquote>
