<h2>v1.11.3 - Recipe Selector Sync Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Recipe selector flickering when changing ingredients</strong>: When placing items in the crafting grid that produced multiple valid recipes, the selector would appear briefly and then disappear. This was caused by a race condition between the client recalculating recipes locally each frame and the server sending the recipe list asynchronously. The selector cache could be cleared between frames, making it invisible.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>SyncRecipesPacket</code> &mdash; now includes the current input items along with recipe outputs, enabling proper client-server synchronization.</li>
<li><code>PolymorphClientHandler.receiveServerRecipes()</code> &mdash; updated to accept input items and store them in <code>lastInputs</code>, preventing redundant local recalculation until inputs actually change.</li>
<li><code>MixinCraftingMenu</code> &mdash; captures current inputs when sending the sync packet to the client, ensuring consistent state between server and client.</li>
</ul>
