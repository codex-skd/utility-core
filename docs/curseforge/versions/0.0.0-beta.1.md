<h2>v0.0.0-beta.1 - Initial port to Minecraft 26.2</h2>

<h3>Port</h3>
<ul>
<li><strong>Full port from the 26.1.2 branch (v1.1.7)</strong> to Minecraft 26.2 / NeoForge 26.2.0.32-beta. All source files compiled without any API changes needed between the two versions.</li>
</ul>

<h3>Features</h3>
<ul>
<li><strong>Recipe Conflict Resolution</strong>: selector widget in the crafting table when multiple recipes match the same inputs.</li>
<li><strong>Negative Damage Safety</strong>: clamps negative damage values to 0 to prevent server crashes.</li>
<li><strong>Corail Tombstone Compatibility</strong>: GUI scale fix, item NBT init fix, mixin error suppression.</li>
<li><strong>OutpostZero Damage Cap</strong>: limits infection damage to 10000.</li>
<li><strong>Automatic Chunk Pregeneration (ChunkGen)</strong>: spiral chunk pregeneration, multi-dimension, progress persistence, keep-alive.</li>
</ul>

<h3>Notes</h3>
<blockquote>The Ender Dragon respawn feature from earlier 26.1.2 releases is <strong>not</strong> included — it was permanently removed (v1.1.7) due to broken visual results with YUNG's Better End Island.</blockquote>
