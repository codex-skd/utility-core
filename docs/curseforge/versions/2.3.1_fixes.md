<h2>v2.3.1 - Vehicle Anti-Cheat Whitelist</h2>

<h3>Feature</h3>
<ul>
<li><strong>Configurable vehicle anti-cheat whitelist</strong>: Added support for whitelisting entity types from vanilla's <code>moved too quickly</code> vehicle anti-cheat check. This prevents spam of warnings like <code>entity.evilcraft.broom (vehicle of X) moved too quickly!</code> when players use fast-moving vehicles from mods (e.g., EvilCraft's broom).</li>
<li>The fix intercepts <code>isVehicleMovingTooFast</code> and <code>checkVehicleMovement</code> in <code>ServerGamePacketListenerImpl</code> to allow whitelisted entity types to move faster than vanilla's default limit without triggering warnings.</li>
<li>New config options in <code>utility_core_fixes-common.toml</code>:
<ul>
<li><code>enableVehicleAntiCheatWhitelist = true</code> — master toggle</li>
<li><code>vehicleAntiCheatWhitelist = ["evilcraft:broom"]</code> — list of entity type IDs (namespace:path) to whitelist</li>
</ul>
</li>
<li>Whitelist entries support exact matches (e.g., <code>evilcraft:broom</code>). Optional mod dependency: EvilCraft.</li>
</ul>
