<h2>v1.11.7 - Diagnostic Release</h2>

<h3>Changes</h3>
<ul>
<li><strong>Added comprehensive server-side logging for recipe selection</strong>: To diagnose the issue where recipe selection always reverts to the first option, added detailed debug logging that tracks:
  <ul>
  <li>When multiple recipes are detected</li>
  <li>When the recipe list is updated or initialized</li>
  <li>The current selection index and total recipes available</li>
  <li>Whether the selected recipe is valid and in the recipes list</li>
  <li>When fallback to first recipe occurs and why</li>
  </ul>
</li>
<li><strong>Enhanced packet handling logging</strong>: Added logging in <code>SelectRecipePacket.handle()</code> to confirm when selection packets are received and processed</li>
</ul>

<h3>Technical Details</h3>
<ul>
<li>All <code>[UtilityCore]</code> logs will now appear in the server log when interacting with the recipe selector</li>
<li>Use these logs to determine the exact point at which selection fails or reverts</li>
</ul>
