<h2>v2.1.0-beta.1 - Bridging Assist</h2>

<h3>Features</h3>
<ul>
<li><strong>Bridging Assist</strong>: new "reacharound" placement feature ported from BridgingMod. Helps you bridge/scaffold by extending block placement to positions you're looking at but not directly reaching, with a crosshair indicator and outline showing where the next block will go.</li>
<li>Slab assist, configurable minimum bridge distance, supported placement axes, per-crouch overrides, and post-placement delay.</li>
<li>Optional soft-dependency integrations with DankStorage and Sable (no hard dependency — only activates if those mods are present).</li>
<li>New keybind to toggle Bridging Assist on/off (default: comma).</li>
</ul>

<h3>Fix</h3>
<ul>
<li><strong>Critical</strong>: QoL previously had no <code>@Mod</code> entrypoint issue affecting the sibling mods (Admin/Fixes) in this same release — see their changelogs. QoL itself already had a working entrypoint.</li>
<li>Fixed a config file conflict between the new Bridging Assist config and the existing QoL config (both targeted the same file); Bridging Assist settings now live in their own client-side config file.</li>
<li>Fixed the bridging crosshair/outline mixins not loading due to an invalid mixin package path.</li>
<li>Fixed the crosshair direction indicator texture not resolving, the outline colour being computed incorrectly, and placement for special compat items bypassing their custom handler.</li>
<li>Removed leftover debug logging from the recipe selector that fired on every crafting grid change; diagnostic logs are now gated behind the existing <code>logDetectedConflicts</code> setting.</li>
</ul>
