<h2>v1.9.0 - Spawn Zone Anti-Mob &amp; Server Rules Manager</h2>

<h3>New Features</h3>
<ul>
<li><strong>No natural mobs in the spawn zone</strong>: <code>spawnSchematic.preventMobSpawns</code> (default true) blocks natural mob spawns inside the spawn schematic bounds (<code>MobSpawnEvent.SpawnPlacementCheck</code>, only <code>NATURAL</code> reasons &mdash; spawn eggs and commands still work). Useful when the schematic has no lighting. The zone was already unbreakable/unplaceable/explosion-proof.</li>
<li><strong>Server Rules Manager</strong>: enforce a curated list of game rules from <code>utility_core/server_rules.json</code> (e.g. <code>"players_sleeping_percentage": 50</code>). On server start each rule is compared against the current server value and <strong>only applied when it differs</strong> (via the <code>GameRules</code> API, no commands). If it already matches, nothing happens. Commands: <code>/utilitycore rules apply</code> and <code>/utilitycore rules status</code>. Removing a rule leaves the server untouched.</li>
</ul>

<h3>Fixes</h3>
<ul>
<li><strong>ChunkGen restart loop</strong>: with a finite <code>chunkGen.maxRadius</code>, generation restarted forever after completing (re-generating the same area). A <code>completed</code> state is now persisted; use <code>/utilitycore chunkgen reset</code> to regenerate.</li>
<li><strong>keepAlive on empty servers</strong>: the idle-pause field is now found by name with the correct unit (<code>nextTickTimeNanos</code>, nanoseconds in 26.2; falls back to the legacy <code>nextTickTick</code>), so an empty server no longer pauses after 60s and freezes the duty cycle.</li>
</ul>

<h3>Config</h3>
<ul>
<li><code>spawnSchematic.preventMobSpawns</code> (default true) &mdash; block natural mob spawns inside the schematic bounds.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>SpawnProtectionHandler</code> &mdash; new <code>onSpawnPlacementCheck</code> handler.</li>
<li><code>ServerRulesManager</code> &mdash; new; reads <code>utility_core/server_rules.json</code> and applies rules on <code>ServerStartedEvent</code> using the <code>GameRule</code> registry.</li>
<li><code>ChunkGenManager</code> &mdash; added persisted <code>completed</code> state and robust keepAlive field discovery.</li>
</ul>

<h3>Notes</h3>
<blockquote>Server operators: the new config key <code>spawnSchematic.preventMobSpawns</code> is added automatically on first start. To change the sleeping percentage, create <code>utility_core/server_rules.json</code> with the rule id <code>players_sleeping_percentage</code> (in-game gamerule names, snake_case).</blockquote>
