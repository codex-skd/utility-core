<h2>v1.0.37 - ChunkGen: Keep Server Alive</h2>

<h3>Fix</h3>
<ul>
<li><strong>Server auto-pause during ChunkGen</strong>: The dedicated server pauses after 60 seconds of inactivity (no players). This stopped chunk generation. Now ChunkGen resets the internal tick timer (<code>nextTickTick</code>) via reflection to keep the server alive while generating.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>ChunkGenManager</code> &mdash; Added <code>keepAlive()</code> method that updates <code>MinecraftServer.nextTickTick</code> field via reflection when generating with no players online.</li>
</ul>
