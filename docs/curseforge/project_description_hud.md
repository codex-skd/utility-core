<h2>&#10024; Overview</h2>

<p><strong>Utility Core HUD</strong> adds a lightweight, fully customizable on-screen display system for Minecraft — a foundation for HUD elements you can toggle, drag, and resize without ever opening a config file. Every element is positioned interactively in-game and saved instantly.</p>

<p>What it covers today:</p>
<ul>
<li><strong>Armor durability status</strong> — always-visible icons showing the condition of your equipped armor</li>
<li><strong>In-game guide book</strong> — a Vellumli-powered book explaining every feature, with instructions to use the <code>/hudmenu</code> command (OP only)</li>
<li><strong>Interactive positioning</strong> — drag, resize and reorient any HUD element with the mouse, no config editing required</li>
</ul>

<br>

<h2>&#129513; Features</h2>

<h3>&#128737;&#65039; Armor Durability Status</h3>
<p>Shows an icon for each equipped armor piece, styled exactly like its inventory slot icon, including the damage overlay. Icons always sit flush against each other — if a piece is removed or fully repaired, the remaining icons close the gap instead of leaving an empty slot.</p>

<h3>&#128214; In-Game Guide Book</h3>
<p>A <a href="https://www.curseforge.com/minecraft/mc-mods/vellumli">Vellumli</a>-powered guide book explains every HUD element and setting. The book instructs users to use the <code>/hudmenu</code> command (requires operator level 2) to open the HUD configuration menu.</p>

<h3>&#127919; Interactive Positioning</h3>
<ul>
<li>Drag any HUD element anywhere on screen with the mouse</li>
<li>Scroll the mouse wheel to switch between vertical and horizontal layout</li>
<li>Use the on-screen <code>+</code> / <code>&minus;</code> buttons to resize it</li>
<li>A gold border marks the editable area while positioning is active</li>
<li>Press <code>Enter</code> to confirm and save, returning to the HUD menu</li>
</ul>

<h3>&#128065;&#65039; Show / Hide Control</h3>
<p>Toggle each HUD element on or off at any time from the configuration menu, independent of the positioning tool.</p>

<br>

<h2>&#9881;&#65039; Fully Configurable</h2>

<p>No config file editing needed — every HUD element is enabled, positioned, oriented and resized directly in-game through the interactive editor, and saved automatically to <code>config/utility_core_hud/</code>.</p>

<h2>&#127918; How to Use</h2>

<ol>
<li>Use the command <code>/hudmenu</code> (requires operator level 2).</li>
<li>Choose <strong>Show</strong> or <strong>Never show</strong> for each HUD element.</li>
<li>Press <strong>Edit position</strong> to enter interactive placement mode.</li>
<li>Drag to move, scroll to switch orientation, use <code>+</code>/<code>&minus;</code> to resize.</li>
<li>Press <code>Enter</code> to save and return to the menu, then <strong>Save</strong> / <strong>Close</strong>.</li>
</ol>
