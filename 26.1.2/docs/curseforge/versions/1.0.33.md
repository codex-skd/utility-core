<h2>v1.0.33 - Automatic Chunk Generation (ChunkGen)</h2>

<h3>Feature</h3>
<ul>
<li><strong>ChunkGen</strong>: Automatic chunk generator that pre-generates chunks in a spiral pattern starting from (0,0), without any external dependencies.</li>
<li><strong>Auto-pause on player join</strong>: Generation pauses automatically when a player joins the server, preventing lag.</li>
<li><strong>Auto-resume on empty server</strong>: When the last player leaves, generation resumes from where it stopped.</li>
<li><strong>Persistent progress</strong>: State is saved to <code>config/utility_core_chunk_gen.json</code> and restored on server restart.</li>
<li><strong>Progress logging</strong>: Logs every 100 chunks generated, plus on pause/resume/complete.</li>
<li><strong>Commands</strong>: <code>/utilitycore chunkgen status</code>, <code>start</code>, <code>pause</code>, <code>stop</code>, <code>reset</code>.</li>
</ul>

<h3>Configuration</h3>
<ul>
<li><code>chunkGen.enabled</code> (default: <code>false</code>) &mdash; Enable/disable the generator</li>
<li><code>chunkGen.chunksPerTick</code> (default: <code>1</code>) &mdash; Chunks per server tick (1-64)</li>
<li><code>chunkGen.maxRadius</code> (default: <code>0</code>) &mdash; Max radius in chunks (0 = unlimited)</li>
<li><code>chunkGen.runWithPlayers</code> (default: <code>false</code>) &mdash; Continue generating even with players online</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>ChunkGenManager</code> &mdash; Spiral generator using concentric square pattern, tick-based, with full state persistence via Gson</li>
<li><code>Config.java</code> &mdash; 4 new config options under <code>chunkGen.*</code></li>
<li><code>UtilityCore.java</code> &mdash; New event listeners (<code>ServerTickEvent</code>, <code>PlayerLoggedInEvent</code>, <code>PlayerLoggedOutEvent</code>, <code>RegisterCommandsEvent</code>)</li>
</ul>
