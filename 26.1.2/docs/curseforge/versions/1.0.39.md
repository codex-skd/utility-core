<h2>v1.0.39 - Dragon Respawn: Force Place Bedrock + Crystal</h2>

<h3>Fix</h3>
<ul>
<li><strong>Dragon respawn with YUNG Better End Island</strong>: If no existing bedrock is found at the positions YUNG searches (dist=7 from portal.above(1)), the mod now places bedrock blocks + EndCrystal entities at the exact coordinates, ensuring the dragon fight can detect them.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>EnderDragonRespawnHandler.placeCrystalWithBedrock()</code> &mdash; Last resort: clears the area, places bedrock, then spawns the end crystal with beamTarget.</li>
<li>YUNG search positions: <code>checkForBEIRespawnCrystals(dist=7, Y=portalY+1)</code> and <code>checkForVanillaRespawnCrystals(dist=2, Y=portalY-2)</code>.</li>
</ul>
