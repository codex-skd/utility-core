<h2>v1.0.40 - ChunkGen: Robust KeepAlive + State File Path</h2>

<h3>Fix</h3>
<ul>
<li><strong>Server auto-pause during ChunkGen</strong>: The keepAlive mechanism now scans all <code>long</code> fields in <code>MinecraftServer</code> at runtime to find the tick timer field (compatible with any Minecraft version).</li>
<li><strong>State file path</strong>: Moved from <code>config/utility_core_chunk_gen.json</code> to <code>utility_core_chunk_gen.json</code> (server root) for better visibility.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>ChunkGenManager</code> &mdash; <code>keepAlive()</code> scans fields with values near <code>Util.getMillis()</code> to identify the tick timer, regardless of its name.</li>
<li>State file path changed to server root directory.</li>
</ul>
